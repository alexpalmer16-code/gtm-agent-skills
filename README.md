# GTM Agent Skills

Practical agent instructions for commercial work, by Alex Palmer.

These skills help sellers and commercial leaders prepare decisions, inspect evidence and retain responsibility for the outcome. Each skill defines the inputs it needs, how to handle uncertainty and what a useful output looks like.

## Initial collection

| Skill | Use it for | Status |
| --- | --- | --- |
| [Meeting preparation](skills/gtm-meeting-preparation/SKILL.md) | Turn account material into a brief, questions and a meeting objective | Draft; synthetic evaluation case included |
| [Buying-window review](skills/gtm-buying-window-review/SKILL.md) | Assess whether account signals justify further discovery | Draft; synthetic evaluation case included |

These are instruction files. They do not run on a schedule, connect to a CRM or send messages by themselves. A compatible agent supplies the execution environment and authorised tools. No field-performance claim is made for either skill.

## Try a skill

Open its SKILL.md, read it, and provide those instructions to your agent with the material you want analysed. Ask the agent to apply the instructions to that material. Start with the included synthetic example before using real account information. This manual method does not install a skill or verify automatic discovery in a particular product.

For example: "Use the meeting-preparation instructions and the supplied example input to prepare my meeting. Keep facts separate from assumptions."

Review citations, missing information and the recommended next step before acting. Never place confidential customer information in this public repository, including issues and pull requests.
